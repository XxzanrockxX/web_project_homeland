# TRIPLETEN ART GALERY

Sitio web estático que presenta una galería de arte y relatos culturales de distintas regiones del mundo, diseñado como un proyecto de presentación y portafolio.

## Descripción

Esta página web muestra una experiencia visual basada en el concepto "De patria a patria". Incluye una introducción, una cuadrícula de imágenes, y secciones dedicadas a tres lugares: Cricieth (Gales), Berea (EE. UU.) y Muramvya (Burundi). Está construida con HTML y CSS, pensado para ser responsive y fácil de visualizar en distintos dispositivos.

## Características

- Página de inicio con encabezado, texto introductorio y imagen principal.
- Cuadrícula de fotos con ocho imágenes representativas.
- Secciones de lugares con información histórica, enlaces a NFT/artistas y contenido cultural.
- Diseño responsive con estilos organizados en archivos CSS modulares.

## Tecnologías

- HTML5
- CSS3
- Diseño responsive

## Estructura de archivos

- `index.html` - Página principal del proyecto.
- `pages/index.css` - Archivo principal de estilos que importa los bloques CSS.
- `blocks/` - Estilos modulares por secciones: `header.css`, `intro.css`, `photo-grid.css`, `places.css`, `media.css`, `footer.css`, `page.css`.
- `vendor/` - Librerías y normalización de estilos (`normalize.css`, `fonts.css`).
- `images/` - Imágenes usadas en el proyecto.
- `fonts/` - Fuentes custom del proyecto.

## Cómo usar

1. Abrir `index.html` en el navegador.
2. Navegar por las secciones para ver la galería y los relatos de cada lugar.
